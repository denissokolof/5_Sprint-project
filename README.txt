Автотесты реализованы для: 

Регистрация
Успешная регистрация.
Ошибку для некорректного пароля.

Вход
Проверка:
входа по кнопке «Войти в аккаунт» на главной,
входа через кнопку «Личный кабинет»,
входа через кнопку в форме регистрации,
входа через кнопку в форме восстановления пароля.

Переход в личный кабинет 
Проверка перехода по клику на «Личный кабинет».
Переход из личного кабинета в конструктор 
Проверка перехода по клику на «Конструктор» и на логотип Stellar Burgers.

Выход из аккаунта
Проверка выхода по кнопке «Выйти» в личном кабинете.

Раздел «Конструктор»
Проверка, что работают переходы к разделам:
«Булки»,
«Соусы»,
«Начинки».
